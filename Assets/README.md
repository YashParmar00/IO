# Assets

- `Scenes/` — Unity scenes
- `Scripts/Core/` — game state and managers
- `Scripts/Player/` — player controls
- `Scripts/Gameplay/` — food, spawning, and gameplay rules
- `Scripts/UI/` — score and user interface
- `Prefabs/` — reusable GameObjects
- `Art/` — sprites and animations
- `Audio/` — sound effects and music
