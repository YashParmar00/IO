# Settings Assets

GameConfig.asset is generated by the Unity Editor menu: Tools > IO > Create-Reset Demo Scene and Prefabs. Its source type is Assets/Scripts/Config/GameConfig.cs.

Change movement, arena, food, growth, bot, and frame-rate tuning in this asset through the Inspector once generated. It is intentionally a Unity ScriptableObject asset, not a hand-written YAML file, so Unity should create and serialize it. The generator preserves an existing GameConfig.asset rather than resetting your balance changes.
