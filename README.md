# IO — Unity Game Project

Starter repository for a Unity 2D mobile arcade game.

## Structure

- `Assets/` — Unity scenes, scripts, prefabs, sprites, audio, and settings
- `Packages/manifest.json` — Unity package dependencies
- `ProjectSettings/` — Unity project configuration placeholders

Open this project with Unity Hub after adding the Unity Editor version you plan to use. This is a starter structure, not a complete playable game yet.
